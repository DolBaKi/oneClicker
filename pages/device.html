기기 정보 입력

    Windows 노트북
    1. 노트북 바닥 라벨의 "모델명" 또는 "Model" 칸을 봅니다. (예: 15Z90R, NT950XED)
    2. 시작 버튼을 오른쪽 클릭 → 터미널(또는 Windows PowerShell)을 열고 아래 명령을 붙여 넣으면 Model 줄에 모델명이 나옵니다. 레노버는 SystemFamily 줄이 판매 이름입니다.
      Get-CimInstance Win32_ComputerSystem | Format-List Manufacturer, Model, SystemFamily
    3. Win + R → msinfo32 입력 → "시스템 모델" 항목을 봐도 됩니다.
    맥북
    1. 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 누릅니다.
    2. 이름 아래 줄(예: MacBook Air (M2, 2022))을 그대로 입력하면 됩니다.

    그래도 모르겠다면 제조사와 시리즈(예: 삼성 갤럭시북)만 입력해도 진행할 수 있어요. 이때는 결과 화면에서 이 모델의 표준 사양과 비교하는 부분만 빠집니다.
